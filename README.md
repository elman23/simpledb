# Simple Database

A Rust port of the simple database implementation presented in the Baeldung tutorial on building a database from scratch in C.

The project follows the original design and concepts while reimplementing them in Rust.

## References

- **Tutorial:** https://www.baeldung.com/linux/c-language-implement-db
- **Original C implementation:** https://github.com/Baeldung/posts-resources/tree/main/linux-articles/simpledb
